# N631期末テスト対策 — 文法 N2

N631クラス向けの2026年12月9日期末テスト対策サイトです。現在利用できる科目は「文法 N2」で、『新完全マスター文法 N2』第1課〜第8課の内容を復習できます。

## 内容

- 日本語で出題するオリジナル四択問題100問。
- 第1課〜第8課の文法形式41項目を収録。
- UIと解説の対応言語は11言語：ベトナム語、簡体字中国語、台湾繁体字中国語、韓国語、スペイン語、イタリア語、ネパール語、ミャンマー語、フランス語、英語、ベラルーシ語。
- 100問すべてに11言語の訳文を用意。
- 41項目すべての文法用語・意味の説明を11言語で表示。
- クイズ開始前に、第1課〜第8課の文法を課ごとの折りたたみ式メニューで確認。
- 問題文または選択肢に文法形式が含まれる場合、該当する形式をクイズ画面の「Rappel」欄に表示（第1課〜第8課）。
- 50/50、「わからない」ボタン。50/50の使用回数を結果に表示。
- 問題番号を入力して、好きな問題へ直接移動可能。
- 問題ごとの正誤フィードバック（正解・不正解・訳文・文法の説明）、章ごとの成績グラフ、復習ポイント、間違えた問題の選択内容と正解・説明を表示。
- ピクセルアートのキャラクターが、吹き出しと表情で学習を応援。
- 学習セッションを自動保存し、複数回の結果を端末内に保存・比較。保存履歴は最初は日本語で表示し、解説言語を選ぶとその言語に切り替わります。
- PCとスマートフォンに対応。アカウントやサーバーは不要。

## 翻訳について

各文法項目の日本語例文には、英語とベラルーシ語で全41項目の訳があります。その他の9言語では、第6課〜第8課の15項目に訳があり、第1課〜第5課の例文は日本語のみです。クイズの100問の訳文は11言語すべてに用意しています。

## 保存データについて

保存履歴の表示言語は、解説言語を選ぶまでは日本語で、選択後はその言語になります。学習履歴はブラウザの localStorage に保存されます。そのため、同じブラウザ・同じ端末であればページを閉じても再開できますが、別の端末やブラウザとは自動同期されません。ブラウザのサイトデータを消去すると、保存した学習履歴も消える可能性があります。新しいセッションを始めるたびに日付と時刻が記録され、過去のセッションは最大40件まで保持します。
